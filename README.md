# Space Museum AR

## Project Description

Space Museum AR is an Augmented Reality
application developed using A-Frame and AR.js.

Users can scan a Hiro marker to view an
interactive miniature Space Museum containing
3D planets, a rocket and an astronaut.

## Technologies Used

- HTML
- CSS
- JavaScript
- A-Frame
- AR.js

## Features

- Hiro marker detection
- Interactive 3D space museum scene
- Animated 3D objects
- Earth colour-changing interaction
- Saturn size-changing interaction
- 3D astronaut model
- Marker detection status banner

3. Run index.html using Live Server.
4. Allow camera access.
5. Point the camera at the Hiro marker.
